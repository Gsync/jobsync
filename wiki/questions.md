# Questions

## How do I add code to an answer?

Click the code block button (the `<>` icon in a square, last in the answer toolbar) to turn the current line into a code block. You can also type ```` ``` ```` followed by a space at the start of a line, or paste code copied from VS Code. Click the button first, then type or paste: selecting several existing lines turns each one into its own block.

While the caret is inside a code block, a **Language** picker appears next to the toolbar buttons. Pick the language to colour the code for it, or leave **Auto-detect** and JobSync guesses the language from the code itself. A block saved from AI chat with a language label such as `ts` keeps that label and shows the picker's placeholder until you choose a language.

Inside the block, Enter adds a new line. Press Enter three times at the end of the block, or the down arrow at the end of the block, to leave it and continue writing normal text.

Code shows in colour on the Questions page and in AI chat replies, in both light and dark mode.
